# Personal Waifu

A website with a 3D anime character that helps you choose anime to watch.

## Current status

Repository setup only. No working app or trained model yet.

## Learning sequence

1. Set up the repository.
2. Build a local website and introduce a licensed 3D character.
3. Connect a baseline anime recommendation chatbot.
4. Create permitted training examples and a separate evaluation set.
5. Fine-tune a model and compare it with the baseline.

## How we work

Review each small plan in Plannotator before editing.
Explain each code change, run the relevant checks, then review the diff.
Pause before the next lesson. Commit and push only when requested.
